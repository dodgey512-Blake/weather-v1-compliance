# V1.0 合规 天气App

Independent weather demo and Android test build. The public site includes the product, VIS, audit, user-owned Feishu documentation and downloadable source package.

Current live sources use NWS only. Unverified commercial Open-Meteo access is disabled. AQI remains unavailable, so incomplete running assessments cannot be applied. Native production, commercial identity, licensed data, store billing and device validation remain release requirements.

Original V1.0 stays at https://dodgey512-blake.github.io/weather-v1/ .
