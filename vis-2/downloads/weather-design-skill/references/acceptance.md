# 天气设计验收

按本次任务范围执行并报告实测边界。

1. 320px与375/390px竖屏、短屏、横屏和键盘展开：顶部、内容、CTA与Tab都可操作。长英文、中文多行及放大文字没有关键信息裁切。
2. 默认中文；切英文后标题、导航、错误、状态、辅助名称一致变化，计划时区与日期不改变。
3. 每个功能文字至少12、正文16、辅助14 CSS px；按合成后的背景检查对比。所有操作命中区≥44×44 CSS px；原生按平台单位复核。
4. 天气昼夜与类别一致；雨是闭合水滴；雪、雾独立；减少动态时保留可辨认静态状态；停止屏幕外持续动画。
5. 导航轻点、拖动松手、取消、快速反向、键盘和页面中断后都归位，当前页语义同步；透明度关闭后仍清楚。
6. 最新、缓存、过期、缺失、模拟各有可见文案与正确恢复操作；模拟来源不显示实时，旧数据不可标为现在。
7. Fixed不改期，训练完整时段有数据，城市浏览不改计划，编辑使旧决定失效，完成/取消不会继续active；保存失败保留输入，反馈无默认正向。
8. SVG可解析且通过object播放；组件大画布可缩放、打开和下载；Skill ZIP真实可解压并有SKILL.md及引用资源。
9. 用实际浏览器与请求验证公开URL。未做的Safari真机、原生辅助功能与性能项直说未做，不继承旧版通过状态。
