# 天气产品设计规范 · VIS 2.0

本 Skill 只服务当前天气项目。天气负责产品身份与日常打开理由；OOTD Lite 免费提供生活建议；跑步是第一个专业场景。不要把欢迎页、首页和导航整体变成运动训练产品。遵循本次请求的范围；检查、讨论、局部改版不自动授权重做所有页面或部署。

## 开始工作

读取当前项目的状态档及正在使用的需求版本，再按实际框架设计。现阶段是 React Web / H5，不以 Liquid Glass 为由改成原生框架。保留已有版本，新增交付使用新编号。品牌尚未正式命名，不把临时名称、占位头像或演示文案当成真实用户资料。

涉及控件材质与手势时读 [导航与状态](references/navigation-and-states.md)。需要颜色、字号与间距时使用 [机器可读变量](assets/tokens.json)。交付前执行 [验收](references/acceptance.md) 中与本次范围有关的项目。

## 视觉基线

1. 夜蓝 `#091019`，内容面 `#111b25`，暖白 `#f4f0e6`，天空蓝 `#72bce8`，荧光绿 `#ddfc68`，风险色 `#ff765f`。以语义变量使用；风险不只靠颜色传达。暖白用于清楚的重点内容，绿只用于主操作、已选项和改善窗口。
2. 中文和功能正文采用平台系统字体；Space Grotesk 用于温度和少量展示标题。正文 16–17、辅助 14–15、功能标签至少 12 CSS px；关键温度可 72–104。不得用小号全大写等宽字承担关键功能信息。排版随大字号重排。
3. Lucide 线性图标为现有体系。导航图标 22 CSS px / 1.8 描边，同层一致；实际命中区至少 44×44 CSS px。原生 iOS 按 44pt 核验，不混用单位。
4. 以 4px 为间距基准，常用 8/12/16/20/24/32。内容卡圆角 20–28，输入 14–16，导航胶囊 999。圆角服从控件用途，不把每个字段再包多层卡片。
5. 页面结构明确为顶部、独立滚动内容、底部。两段式首页与三段式应用页分别定义网格；短屏、横屏、键盘时底部不能掉出视口。手机网页不重复画假系统时间和刘海。

## 信息与双语

1. 默认简体中文，可切换英文。导航、字段、校验、状态、天气类别、通知和辅助名称一起切换；用户自由输入不自动翻译。
2. 允许显示来源机构原名。官方警报原文保留并标明语言，不把机器翻译伪装成官方英文原文。时间按计划所在地时区；界面语言、单位与时区分别保存，切语言不改变计划日期或单位。
3. 英文长词、中文多行、大字号都要保留完整含义。不得用截断替代天气警报、失败原因和主操作。空值显示缺失，不显示 0% 冒充无雨。
4. 首页顺序优先：地点与重要预警、当前天气、24h趋势、当天重点、OOTD与下一条计划。24h/3天详情按日期分组；分析页使用真实时间序列，禁止装饰曲线冒充证据。

## 天气、数据和任务

1. 晴、云、雨、雷暴、雪、雾分别表达；昼夜独立判断。夜间晴天不画太阳，雪冰不归入下雨。未知类别采用中性状态和文字，不编造天气。
2. 雨使用上尖下圆的闭合水滴，可用前后层、不同速度、有限风角与涟漪。禁止贯穿页面的长直线。动画在信息后方，不遮盖温度、警报与控件。缺雨强/风向数据时不声称动态精确对应实况。
3. 数据模式、来源、缓存方式、新鲜度分别建模。`fresh`、`cached`、`stale`、`unavailable` 是展示状态；`scenario` 需全程显著标识，模拟数据不可进入真实决定或实验指标。有效缓存可以使用，过期数据必须带时间，缺失数据暂停确定性建议。
4. 跑步建议比较开始至结束的完整窗口，遵守地点、时区、未来72h与可调范围。Fixed 不生成改期；没有可用窗口明确表达；严重预警优先。建议有来源、数据时间、有效期与保留入口。
5. 计划生命周期区分待执行、已完成、已取消；编辑关键输入使旧建议与旧决定失效。完成后不继续显示为下一次计划。变化页必须由新旧快照变化驱动，不用固定88%制造提醒。
6. 表单先提供地点、开始、时长、可调范围。可选字段只在确实有作用时展示。保存失败保留草稿；删除提供撤销或明确确认；反馈初始未选择且训练后触发。无需调整直接保留，有变更才展示比较确认。

## 动态与交付

按压约120ms，控件状态约200ms，页面转场约320ms；按任务距离与反馈调整，不在每页重复大幅入场。静止导航不持续摆动。支持减少动态、减少透明度和对比增强；低能力环境仍可操作。

组件库采用一个可浏览的大画布，编号、组件实物、动态状态和源文件链接并列。动态 SVG 用 `object` 载入；提供单独 SVG 和 Skill 下载。固定示例标明演示数据。公开链接的实际访问、移动布局、语言切换和操作状态需要本次验证，不能借用旧版验收结果。
